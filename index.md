# 👋 CKMImageNet Dataset Showcase
This is my GitHub Pages site for displaying the [CKMImageNet Dataset](https://github.com/zyktzCKM/CKMImageNet).

## 📚 Dataset Introduction
CKMImageNet is a high-precision image dataset with location-based channel knowledge, generated by ray-tracing simulation.

## 🚀 Key Features
1. Categorized into Urban/Rural scenarios
2. Contains Channel Gain, AOA, AOD parameters
3. 81 partially overlapping subareas per Base Station (BS)
